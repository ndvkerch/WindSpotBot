# API WindSpotBot

API для взаимодействия с ботом находится в разработке. На данный момент бот работает через Telegram API, и внешний API не реализован.

## Планируемый функционал

- **Эндпоинты**:
  - `GET /spots`: Получение списка спотов.
  - `POST /checkins`: Создание чек-ина.
  - `GET /activity`: Получение активности на спотах.
  - `POST /subscriptions`: Управление подписками.
- **Аутентификация**: Планируется использование API-токенов.
- **Формат данных**: JSON, основанный на Pydantic-моделях (`Spot`, `Checkin`, `Subscription`).

## Текущий статус

- Telegram API: Используется через библиотеку `aiogram` для обработки команд и callback'ов.
- Внешний API: Не реализован, в планах после стабилизации основного функционала.
