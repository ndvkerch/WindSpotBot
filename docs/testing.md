# Тестирование WindSpotBot

Тестирование проводится для обеспечения стабильности и корректности работы бота. В проекте планируется использование `pytest` для модульных и интеграционных тестов.

## Настройка тестирования

1. Убедитесь, что зависимости установлены:
   ```bash
   pip install pytest pytest-asyncio
   ```

2. Создайте файл `pytest.ini` в корне проекта:
   ```ini
   [pytest]
   asyncio_mode = auto
   ```

3. Создайте директорию `tests/` для тестов:
   ```
   tests/
   ├── __init__.py
   ├── test_services.py
   ├── test_repositories.py
   └── test_handlers.py
   ```

## Запуск тестов

```bash
pytest tests/
```

## Текущие тесты

- **В разработке**:
  - Тесты для `SpotService` (добавление спота, проверка расстояния).
  - Тесты для `GeoService` (кэширование координат, расчёт расстояний).
  - Тесты для `CheckinService` (создание чек-инов).
  - Интеграционные тесты для хендлеров (`/checkin`, `/spots`, `/activity`, `/add_spot`).

## Ручное тестирование

До реализации автотестов проводите ручное тестирование:

1. Запустите бота:
   ```bash
   python -m src.bot
   ```

2. Проверьте команды:
   - `/start`: Показывает главное меню.
   - `/checkin`: Запрашивает геолокацию, отображает список спотов, создаёт чек-ин.
   - `/spots`: Запрашивает геолокацию, отображает список спотов.
   - `/activity`: Запрашивает геолокацию, показывает активность (погода, пользователи, чаты).
   - `/add_spot`: Запрашивает название, геолокацию, описание, добавляет спот.

3. Проверьте базу данных:
   ```bash
   sqlite3 data/database.db
   SELECT * FROM spots;
   SELECT * FROM checkins;
   ```

## Известные проблемы

- Кэширование координат: Координаты не извлекаются из кэша (исправлено в `GeoService`).
- Ошибки API Open-Meteo: Код 400 (исправлено в `WeatherService`).
- Отсутствие метода `get_by_spot` в `CheckinRepository` (исправлено).
- Ошибка `chat_id` в `ChatService` (исправлено).
