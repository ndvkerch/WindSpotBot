# Техническое задание (ТЗ) для WindSpotBot

## Общее описание

- **Название проекта**: WindSpotBot  
- **Цель проекта**: Telegram-бот для кайтсерферов с функциями чек-ина, планирования, просмотра спотов, прогноза погоды, уведомлений, чатов с хэштегами, оценки спотов и админ-статистики.  
- **Платформа и технологии**: Telegram, библиотека `aiogram` 3.x, Python 3.10+.  
- **Целевая аудитория**: Кайтсерферы, администраторы спотов.  
- **Особенности проекта**:  
  - Морской, кайтерский, сёрфовый тон с юмором («лови ветер», «йо, бро»).  
  - Тематические эмодзи: 🤙, 💨, 🏄‍♂️, 🌊, 🪁, ☀️.  
  - Сообщество: `@WindSpotRU` для обсуждений и новостей.  

## Функциональные требования

### Основные команды и сценарии

1. **Команда `/start`**  
   - Регистрирует пользователя (ID, имя, username, часовой пояс по геолокации).  
   - Приветствие:  
     ```
     🤙 Йо, {name}! Добро пожаловать на борт WindSpotBot! 🏄‍♂️
     Лови ветер, находи споты и тусуйся с кайтерами! 💨
     💬 Заходи в @WindSpotRU, там волна новостей и движухи!
     ```  
   - Динамическое меню (например, «Покинуть спот» для активного чек-ина).  

2. **Чек-ин**  
   - **Тип 1 («На месте», ✅)**: Время пребывания 1-6 часов, автодеактивация.  
   - **Тип 2 («Прибуду», ⏳)**: Время до прибытия 1-3 часа, автодеактивация/удаление.  
   - **Тип 3 («Планирование», 📅)**: Дата (до 7 дней), время, спот.  
   - Ограничение: Один активный чек-ин (типы 1 или 2).  
   - Использует кэшированную геолокацию (TTL=1 час).  
   - Показывает N ближайших спотов (`NEARBY_SPOTS_LIMIT`).  
   - Пример:  
     ```
     ✅ Йо, ты на Спот 1! Лови вайб! 🏄‍♂️
     Сколько тусить будешь?
     [1 час] [2 часа] [3 часа] [4 часа] [5 часов] [6 часов]
     ```  

3. **Планирование посещений**  
   - Чек-ин типа 3.  
   - Отображается на страничке спота (N записей, `PLANNED_VISITS_LIMIT`):  
     ```
     📅 Планы на волну:
     1. 20.04.2025 14:00, <a href="tg://user?id=123">@ivan123</a>
     2. 21.04.2025 10:00, <a href="tg://user?id=456">@anna</a>
     ```
