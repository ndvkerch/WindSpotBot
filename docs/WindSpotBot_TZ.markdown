Техническое задание: WindSpotBot
1. Общее описание
Название: WindSpotBotЦель: Telegram-бот для кайтсерферов с функциями чек-ина, планирования поездок, просмотра спотов, прогноза погоды, уведомлений, чатов с хэштегами, оценки спотов, геймификации, социальных функций и админ-статистики. Подготовка к будущему веб-приложению.Платформа: Telegram, библиотека aiogram 3.x.Язык: Python 3.10+.Целевая аудитория: Кайтсерферы, администраторы спотов.Сообщество: @WindSpotRU для обсуждений и новостей.Особенности:  

Морской, кайтерский, сёрфовый тон с юмором («лови ветер», «йо, бро»).  
Тематические эмодзи: 🤙, 💨, 🏄‍♂️, 🌊, 🪁, ☀️, 📅, 😕, ✅, 🔔, 📍, ⏳.  
Изолированные сервисы и репозитории для масштабируемости.  
Конфигурация через .env с валидацией pydantic.  
Тестирование (покрытие >80%) и документация.  
Подготовка к переходу на PostgreSQL и веб-приложение.

Статус:  

Бот запущен и работает: ✅ Реализовано.

Напоминания для чек-инов типа 3 в 8:00 утра:  SELECT * FROM checkins WHERE type = 3 AND active = 1 AND planned_date = ?;


Удаление сообщений по TTL (MESSAGE_TTL_DAYS, если используется база spot_messages).  
Расширение:  
Предупреждение о скором истечении чек-инов (интервал 2 минуты).

spots: id, name, latitude, longitude, description.

spot_messages (опционально): id, spot_id, user_id, text, created_at.Индексы:

Миграция для чек-инов типа 3:

9. Технические требования
Чек-ины типа 3:  

Хранение: planned_date (DATE), planned_time (VARCHAR(20)), active_until (DATETIME).  
Удаление:  
DELETE FROM checkins WHERE id = ? (отмена).  
DELETE FROM checkins WHERE type = 3 AND active_until < ? (фоновая задача).


Напоминания: SQL-запрос SELECT * FROM checkins WHERE type = 3 AND active = 1 AND planned_date = ? в 8:00 утра.  
Фильтрация спотов: SpotService.get_nearby_spots(user_id, limit=NEARBY_SPOTS_LIMIT).

Уведомления:  

Теги: re.sub(r'[^a-zA-Zа-яА-Я0-9_]', '', spot_name.replace(" ", "_")).  
Отправка через bot.send_message в темы спотов или общий чат.

Фоновая задача:  

APScheduler для удаления чек-инов и отправки напоминаний.

Логирование:  

Создание, отмена, удаление чек-инов, отправка напоминаний.

12. Замечания
Темы спотов:  

Возможны ошибки:  WARNING - Тема для спота 'Татарка (Ехохо)' не найдена.


Решение: Отправка в общий чат:  if thread_id:
    await bot.send_message(chat_id=CHAT_ID, message_thread_id=thread_id, text=text, parse_mode="HTML")
else:
    await bot.send_message(chat_id=CHAT_ID, text=text, parse_mode="HTML")
    logger.warning(f"Тема для спота '{spot_name}' не найдена, отправлено в общий чат")



Callback-ответы:  

Добавить await callback.answer() во все хендлеры для избежания ошибок:  ERROR - Ошибка в callback: Telegram server says - Bad Request: query is too old

Оптимизировать запросы к SpotService.get_nearby_spots через кэш.
