# WindSpotBot
Telegram-бот для кайтсерферов с чек-инами, спотами, погодой и чатами.

## Активация виртуальной среды

### Перейдите в корень проекта
cd C:\Users\user\windspotbot

### Создать venv
python -m venv venv

### Активировать
source venv/bin/activate    # Linux/macOS
venv\Scripts\activate      # Windows

### Установить зависимости
pip install -r requirements.txt

### Работать с проектом...
### ...

### Деактивировать
deactivate

## Установка
```bash
pip install -r requirements.txt
cp .env.example .env
```
## Запуск
```bash
python -m src.bot
```
